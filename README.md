## 🚀 Featured Project

### 🛡️ SafeBrowse AI — Remote Browser Isolation & Web Threat Detection

A security platform that makes web browsing safer by running risky sites in isolated browser sessions and scoring them before the user ever touches them.

| | |
|---|---|
| 🧱 **Browser isolation** | Disposable Chromium sessions in Docker containers |
| 🖥️ **Remote browsing** | Interactive isolated sessions streamed through noVNC |
| 📊 **Trust scoring** | 10-factor website trust score |
| 🎣 **Threat analysis** | Suspicious URL and phishing detection, ClamAV scanning, AI-assisted analysis |
| 📈 **Monitoring** | Session management and risk monitoring |

**Stack:** React · Node.js · Hono · Python · Flask · Docker · PostgreSQL · noVNC · ClamAV

> Graduation project at An-Najah National University, supervised by Dr. Amjad Hawash. Accepted for exhibition at **TEDI–Najah EXPO**.
